# LEVEL 16: OUTPUT PREDICTION – TRICKY SQL QUESTIONS (20 QUESTIONS)

For each question, predict the result before executing the query.

276. What does this return?

```sql
SELECT *
FROM employee
WHERE salary > 50000 AND salary < 90000
OR department_id = 102;
```

277. What is the difference in results between these queries?

```sql
SELECT *
FROM employee
WHERE salary > 50000
AND department_id = 102
OR department_id = 103;
```

```sql
SELECT *
FROM employee
WHERE salary > 50000
AND (department_id = 102 OR department_id = 103);
```

278. What happens here?

```sql
SELECT *
FROM employee
WHERE email = NULL;
```

279. What does this return?

```sql
SELECT COUNT(*), COUNT(email)
FROM employee;
```

280. What is the output?

```sql
SELECT DISTINCT city, gender
FROM employee;
```

281. What is the difference between these queries?

```sql
SELECT COUNT(city)
FROM employee;
```

```sql
SELECT COUNT(DISTINCT city)
FROM employee;
```

282. What happens here?

```sql
SELECT AVG(salary), SUM(salary), COUNT(*)
FROM employee
WHERE department_id = 999;
```

283. Predict the output:

```sql
SELECT department_id, COUNT(*)
FROM employee
GROUP BY department_id
ORDER BY COUNT(*) DESC;
```

284. What is the result?

```sql
SELECT gender, AVG(salary)
FROM employee
GROUP BY gender
HAVING AVG(salary) > 70000;
```

285. What happens if we execute?

```sql
SELECT department_id, employee_name
FROM employee
GROUP BY department_id;
```

286. Predict the result:

```sql
SELECT *
FROM employee
ORDER BY salary DESC
LIMIT 1 OFFSET 1;
```

287. What is the result?

```sql
SELECT COUNT(DISTINCT email)
FROM employee;
```

288. What is the difference between the following?

```sql
SELECT *
FROM employee
WHERE salary BETWEEN 50000 AND 90000;
```

```sql
SELECT *
FROM employee
WHERE salary > 50000 AND salary < 90000;
```

289. Predict the result:

```sql
SELECT department_id, MAX(salary)
FROM employee
GROUP BY department_id
HAVING MAX(salary) > 100000;
```

290. What happens here?

```sql
SELECT *
FROM employee
WHERE NOT (city = 'Hyderabad' OR city = 'Mumbai');
```

291. What is the result?

```sql
SELECT *
FROM employee
WHERE employee_name LIKE '_____%';
```

292. Predict the output:

```sql
SELECT department_id, SUM(salary)
FROM employee
GROUP BY department_id
ORDER BY SUM(salary) DESC
LIMIT 2;
```

293. What happens when DISTINCT is applied to multiple columns?

```sql
SELECT DISTINCT city, gender
FROM employee;
```

294. What happens if LIMIT is used without ORDER BY?

```sql

FROM employee
LIMIT 5;
```

295. What is the difference between these queries?


# PERSONAL PRACTICE RULES

1. Write every query yourself.
2. Execute it in MySQL Workbench.
3. Verify the output manually.
4. Experiment with different values and conditions.
5. Try alternative ways to solve the same question.
6. For tricky questions, predict the output before execution.
7. Explain your query as if you are answering an interviewer.
8. Maintain a separate file for questions you could not solve.

**Important:** For UPDATE and DELETE experiments, use a copy of your practice database or restore your original records before repeating the exercises.

**Next learning milestone:** Once you master this workbook, move to SQL JOINs, subqueries, correlated subqueries, CTEs, window functions, indexes and query optimization.
